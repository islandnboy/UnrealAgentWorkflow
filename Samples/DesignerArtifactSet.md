# Creator 제작 산출물 구성 예시

포트폴리오용 Case Study 하나는 다음 Artifact를 한 묶음으로 구성합니다.

## 01 — 제작 요청

~~~text
기획자 자연어 요청
~~~

무엇을 만들고 싶은지, 무엇을 보존해야 하는지, 어떤 느낌을 원하는지를 보여줍니다.

## 02 — 제작 계약

~~~text
Goal
Scope
Requirements
Acceptance
~~~

자연어가 어떤 실행 계약으로 바뀌었는지 보여줍니다.

## 03 — AI Agent 실행 기록

~~~text
Workflow / Step
Skill
Actual Tool
Artifact
Validation
Next Action
~~~

Agent가 실제로 어떤 경로로 작업했는지 보여줍니다.

## 04 — Unreal 제작 결과

권장 공개 이미지:

- 제작 전
- 1차 제작 결과
- Creator가 수정한 결과
- 최종 수용한 결과

가능하면 같은 camera / viewport 기준으로 비교합니다.

## 05 — 검증 근거

기술적 근거 중 포트폴리오에 의미 있는 것만 요약합니다.

예:

- 생성된 Actor 수
- 입력 / 출력의 적용 범위
- 저장 / 재로드
- 형상 정합성
- 충돌 / Runtime 재조회
- 재생성 시 기존 결과 보호

대용량 로그 전체를 공개할 필요는 없습니다.

## 06 — Creator 검수

~~~text
좋았던 점
문제점
수정 지시
직접 Editor에서 수정한 값
최종 승인 여부
~~~

기획자의 판단 역시 결과물의 일부로 남깁니다.

## 07 — 반복 개선

~~~text
초기 결과
→ Creator 검수
→ 필요한 부분만 수정
→ Validation
→ 수용된 결과
~~~

이 한 묶음이 Agent Workflow 포트폴리오의 기본 Case Study 단위입니다.
